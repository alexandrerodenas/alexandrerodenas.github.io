Naolib MCP — Démo Interactive

Interrogez les transports en temps réel de Nantes (bus, tramway) en langage naturel. Un modèle d'IA local (Qwen2.5-3B) tourne 100 % dans votre navigateur via WebAssembly, choisit les outils MCP appropriés, et vous répond en français.

🧠

IA Locale (wllama)

Le modèle Qwen2.5-3B-Instruct est téléchargé une fois depuis HuggingFace (~2 Go) et s'exécute entièrement dans votre navigateur via WebAssembly — aucun serveur externe, aucune donnée envoyée.

🔧

Outils MCP (10 outils)

Le MCP naolib expose 10 outils SIRI : recherche d'arrêts, passages en temps réel, alertes, positions des véhicules, horaires, équipements, etc.

🔄

Appel d'outils automatique

L'IA analyse votre question, sélectionne le bon outil avec les bons paramètres, appelle l'API Naolib, puis formule une réponse naturelle avec les résultats.

🏗️ Comment ça marche ? (Architecture)

Cette page démontre le concept de MCP (Model Context Protocol) entièrement côté client :

  1. Chargement du modèle — wllama télécharge le GGUF Qwen2.5-3B-Instruct depuis HuggingFace et l'exécute via WebAssembly dans votre navigateur.
  2. Prompt + outils — Votre question est envoyée au modèle avec une liste d'outils disponibles (les 10 fonctions MCP Naolib) au format JSON.
  3. Décision d'outil — Le modèle répond soit directement, soit avec un appel d'outil au format { "tool": "...", "arguments": {...} }.
  4. Exécution — Le JavaScript exécute la fonction MCP correspondante, qui appelle l'API SIRI Naolib.
  5. Réponse naturelle — Le résultat de l'outil est renvoyé au modèle qui formule une réponse en langage naturel.
// Schéma simplifié :
Utilisateur → "Quand passe le tram à Commerce ?"
↓ LLM (function calling)
{ "tool": "search_stop", "arguments": { "query": "Commerce" } }
↓ MCP Tool → API SIRI
Résultat: StopPoint:COMM
↓ LLM (function calling)
{ "tool": "get_stop_monitoring", "arguments": { "stop_id": "FR_NAOLIB:Quay:2687" } }
↓ MCP Tool → API SIRI
Résultat: Tram A → Beaujoire, 14:23 ✓ | 14:38 ✓
↓ LLM (réponse finale)
"Le prochain tram A à Commerce passe à 14h23 direction Beaujoire…"
💡 Note : Les outils nécessitant une clé API (stop_monitoring, vehicle_monitoring, estimated_timetables) retourneront une erreur si la clé n'est pas configurée. Les outils SIRI Lite (discover_lines, discover_stops, traffic_alerts, general_messages, facility_status) fonctionnent sans clé.
